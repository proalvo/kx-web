# kx-web - Publish your kayak cross competition results
This is public results website for Kayak Cross competitions (companion to KX-Results)

This is public repository for the `kx-web` software - but **you do not need to install this software, if you use [wwcf.fi/kx-results](https://wwcf.fi/kx-results) for your competitions to publish the results in real time**.

Before you can publish the the results, you need to do following:
1. install the `kx-results`
2. send an email to kari.nykanen@wwcf.fi to get organisation key for the kx-results(*). This enables to publish results on [wwcfi.fi/kx-results](https://wwcfi.fi/kx-results).
3. organize you competition.

Note: *) This is just temporary solution as the code is missing 'self service' to create a organization key which is needed to connect your local `kx-results` to `kx-web`.
